# NOCTE – landingspagina

Vibe-coded landingspagina voor het fictieve parfummerk NOCTE (schoolopdracht Creative Automation, Artevelde Hogeschool, 2026). Gebouwd met Claude Code, gepubliceerd via GitHub Pages:
https://syldevos2004-cell.github.io/creativeautomation-nocte/

- `index.html` – hero met campagnefilm, merkverhaal, vier geuren, Night Pass-CTA met embedded MailerLite-form
- `style.css` – huisstijl (Bricolage Grotesque, nacht #160C22, pink #EE92C2, hoofdkleur hsl(46,36%,44%) als accent) + styling van het MailerLite-form
- `img/` – AI-bewerkte productbeelden met NOCTE-etiket, `video/` – campagnefilm 15 s (9:16)
